# LexHelper 应用图标

## 来源与设计
- 本任务原创几何绘制：蓝色合拢字典、深蓝书脊、浅色页边与白色 L；没有外部图片、商标、字体或第三方素材。
- `生成图标.ps1` 是唯一可编辑几何源；坐标基于 256×256 画布。颜色为 `#185ABC`、`#10418F`、`#F4F9FF`、`#6DCFFF`。
- 16/20/24 像素省略书签，保持字典轮廓、L 和页边；32 像素及以上显示浅蓝书签。所有尺寸透明背景、4 倍超采样。
- 不新增窗口、控件或交互，沿用现有原生单文档窗口，不涉及 Tab、布局或主题重构。图形以轮廓和 L 识别，不仅依靠蓝色。

## 离线复现
在项目根目录使用 Windows PowerShell 7（`pwsh.exe`）：

```powershell
pwsh.exe -NoProfile -ExecutionPolicy Bypass -File .\resources\生成图标.ps1
```

默认更新相邻的 `app.ico`，可用 `-OutputPath <已存在目录中的文件路径>` 在测试临时区生成另一份并比较 SHA256。生成器仅使用 Windows 自带的 .NET `System.Drawing`，无需额外库、字体、网络或编译器；在相同 Windows/.NET 绘图环境下可逐字节复现。不同 GDI+ 版本的抗锯齿结果可能不同，以版本控制中的 ICO 为构建输入。

ICO 含 16/20/24/32/40/48/64/128/256 九个尺寸，采用未压缩 32 位 DIB（BGRA、透明 alpha、兼容 AND 掩码）。RC 编译时直接嵌入，不在普通构建中运行生成器。应用只需原有单个 EXE，不依赖脚本、.NET 或外置图标文件。

## Win32 生命周期与 DPI
- `IDI_LEXHELPER` 为唯一应用图标组，用于 EXE Shell 提取、窗口类和窗口大小图标。
- 图标使用 `LoadImageW` 指定 `GetSystemMetricsForDpi` 提供的大小尺寸，检查加载失败；不使用 `LR_SHARED`。`UniqueIcon` 唯一拥有句柄并用 `DestroyIcon` 释放。
- 类图标使用启动时系统 DPI，存活至窗口销毁、类注销之后；每窗口图标在 `WM_CREATE` 按实际窗口 DPI 加载，并在 `WM_DPICHANGED` 和设置/主题变更时重载，不改变 manifest 或 DPI awareness。
- 窗口与窗口类仅借用句柄；`WM_SETICON` 返回的旧句柄不表示转移所有权。先完整加载新大小图标，再替换两个窗口句柄，最后释放旧图标；加载失败保留旧的一对。正常退出先销毁窗口并注销类，成员 RAII 随后释放图标。
- 所有窗口回调内失败沿用现有 `noexcept` 回调捕获逻辑，异常不会越过系统边界。

## 验收边界
自动化可验证资源、尺寸、透明像素、句柄、DPI 尺寸与关闭；资源管理器/标题栏/任务栏在真实桌面、不同主题、多显示器 DPI 的最终视觉效果仍需交互验收。Windows Shell 缓存可能延迟显示新的 EXE 图标，不自动修改系统缓存。
