# 图标失败回归测试（TC-006 / R1）

独立测试项目，不修改主 CMake、生产代码或既有 core 测试。测试 TU 包含原 `src/gui/main.cpp`，Windows SDK 头先包含，宏只在生产源包含期间替换必要 API 调用，不使用 `private` 访问技巧、生产开关或复制算法。

成功加载仍调用真实 LoadImageW，账本逐次记录自有 HICON，失败仅由调用序号返回空。DestroyIcon 监视释放次数及仍被窗口/类借用的非法销毁；GetIconInfo 证明旧句柄有效（其临时位图立即释放）。真实注册类/创建窗口/消息循环/关闭照常执行；监视 WNDPROC 原样转发生产 noexcept procedure，错误 MessageBox 仅记录以避免阻塞。

覆盖 2 个直接加载失败、2 个 WM_CREATE 失败、3 种重载消息各 2 个失败（含每次成功恢复），共 10 个失败场景。断言不是只检查 PASS 输出：错误码、加载数、销毁顺序、WM_SETICON 次数、旧/新窗口句柄及有效性、callback 返回值、失败创建、菜单/类/窗口释放、正常退出码均由程序验证，任一失败返回 1。句柄账本区分已销毁记录与新生命周期，允许 Windows 重用数值。

只创建当前进程自己的隐藏窗口，拒绝提升令牌，不广播、不强杀、不改系统词库/ACL、不读取私人样本。生产 run 的异步 refresh 只查询系统路径与文件状态，正常关闭按原逻辑等待。WM_DPICHANGED 使用当前 DPI 和窗口矩形验证同一重载分支，不声称真实跨屏测试。

## 运行
先创建 `D:\temp\aiRunner\opencode` 下本任务独立目录，仓库根执行：
```powershell
pwsh.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\应用图标失败测试.ps1 -TemporaryDirectory 'D:\temp\aiRunner\opencode\<本任务唯一目录>\failure-test' -Configuration Release
```
脚本设置 TEMP/TMP、清除样本变量，使用已确认的 VS2026 CMake（可显式传 `-CMakeExecutable`）、x64/v145，构建专属目标并执行 `icon_failure`。可选 `-Configuration Debug`。输出 configure.txt、build.txt、ctest.txt；重复同目录同配置会覆盖这些局部日志，应先持久保存所需证据。主项目完整构建/五项回归另行运行。

## 维护边界
- Win32 调用名变动时同步调整测试包装；保持 SDK 声明不被宏改写，包含后立即 undef。
- 真实主题子类可改变外层 SendMessage 返回值；以监视回调记录的生产 procedure 返回值和状态为依据，不将外层返回强行视为 0。
- 测试专属项目关闭引入的主项目 BUILD_TESTING，只构建图标测试目标及必要库；不注册/执行原安全测试，不安装工具、不联网。
- 尚未覆盖错误弹窗自身再次抛异常的兜底分支；本回归针对 LoadImage 失败的生产 catch/恢复和所有权契约。
