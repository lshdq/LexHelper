# LexHelper

Windows 原生新世纪五笔码表工具：导入用户自己的搜狗 CWB 新世纪表或规范化文本，整体重建微软五笔 `imscwubi` lex。**不附带任何搜狗或微软词库。**

## 快速上手（不改系统）

1. 构建 Release 后，普通权限打开 `out/vs2026/Release/LexHelper.exe`，无需先以管理员运行。
2. 点击“打开码表”，选择自己的 CWB 备份；程序自动读取 **WBC3（新世纪）**，不混入 WBC1/2，也不导入配置或皮肤。项目未内置任何私人词库。
3. 等待导入完成，核对来源、记录数与预览。权重是导入后的 lex 代价，越小越靠前，不是搜狗原始词频。导入出错时不要安装；错误不会被当成部分成功。
4. 点击“另存新 lex”，选择一个**尚不存在**的文件名。原 CWB 不变，任何已有输出均拒绝覆盖；另存不安装系统词库。

## 可选：系统备份、安装与恢复（高风险）

仅在已获授权、具有系统级恢复途径的可恢复 Windows 10/11 x64 测试环境操作；**不保证所有 Windows 或真实输入法效果**。先读 [部署与权限说明](docs/部署与权限说明.md)。

1. 点击“管理员重新打开”，由 Windows UAC 打开新实例；不会自动执行系统操作，原普通权限窗口保留。安装时必须在**新管理员窗口重新导入**自己的码表、检查预览，再点击并确认操作；不能沿用旧窗口的导入状态。
2. 查看日志中的备份根目录（由 Windows ProgramData 已知文件夹下的 `LexHelper\Backups` 确定，具体路径/API 见部署说明）。可先点“系统备份”，保留返回的独立 `backup-…` 目录；每次安装也会先新建备份，不覆盖历史。不要修改备份载荷、清单或权限。
3. 点“备份并安装”，核对来源、记录数、目标和备份位置，阅读警告后明确确认；默认是取消。无法安全读取或恢复完整安全属性时会拒绝，不应手工放宽系统 ACL 绕过。
4. 需恢复时，在管理员实例点“恢复备份”，选择日志记录的完整备份目录（不是单个 lex），核对后确认。恢复无需导入码表；仅接受可验证 v2 备份与匹配的当前状态，旧版、损坏或未知状态会拒绝。恢复前也会创建当前状态恢复点。
5. 安装/恢复完成后保存其他工作，**注销并重新登录**，再人工检查输入法效果；程序不终止输入法/共享文本服务。失败请保留日志、备份与错误列出的副本，不因目录存在就认定成功或回滚完整。

部署仅替换 CHS 目录项，不原位改写其他硬链接指向的原实体。备份恢复内容、存在性和完整安全属性，**不恢复硬链接关系或文件 ID**；不保证跨文件、断电或崩溃原子性，Windows 更新也可能覆盖结果。真实管理员特权、TrustedInstaller/审计安全属性及输入法兼容性尚未实测，模拟测试不能代替这些验收。

## 构建

Windows x64，已核实 VS2026 Build Tools、MSVC 14.51 / v145、Windows SDK 10.0.26100.0；C++23（实际 MSVC `/std:c++latest` 由 CMake 选择）。无需安装依赖或联网。

```powershell
pwsh.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\构建.ps1 -Configuration Debug
pwsh.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\构建.ps1 -Configuration Release
```

若 cmake/ctest 已在 PATH：`cmake --preset vs2026`，`cmake --build --preset debug`，`ctest --preset debug`。程序在 `out/vs2026/Debug/LexHelper.exe`。独立核心构建可以 `-DLEXHELPER_CORE_ONLY=ON -B out/core-only` 使用不同目录。

## 导入与候选顺序

- CWB：只在内存读取 ZIP 的精确路径 `usr/wbCustom3.bin`（WBC3）；不提取配置/皮肤，不混入 86/98 表。支持 store 与 deflate，检查目录、长度、CRC、重复表与膨胀上限。也支持独立 WBC3 文件。
- 文本：UTF-8（可 BOM）或带 BOM 的 UTF-16LE；每行 `编码<TAB>词条` 或 `词条<TAB>编码`，可增加第三列非负整数频次。两种方向均为**频次越高越靠前**，等频按行序；无频次按行序。一个文件须保持列方向及列数一致；空行和行首 `#` 注释可用，其余坏行带行号报错。若两列都像 a-z 编码，拒绝猜测。
- lex：支持 1.1、固定 0x40/0xA8 索引/记录布局，严格校验 Unicode、索引及排序；不是用户短语 `.dat`。
- 格式识别：扩展名大小写不敏感；`.txt/.tsv` 明确按文本，`.cwb/.lex/.wbc3` 固定对应二进制类型，冲突或损坏整份拒绝、不会失败后回退文本。未知/无扩展仍支持规范文本，以 BOM、完整 ZIP 标记及二进制/文本包络区分；`PK`、`WBC1/2/3`、`imscwubi` 开头的合法词条不要求 BOM。详细优先级见[核心格式与边界](docs/核心格式与边界.md#文件入口的类型判定)。
- 编译按编码字典序，再按 lex weight 从小到大，相同 weight 稳定保持输入次序；同码同词重复项拒绝，不静默去重。文本频次及 WBC3 候选顺序转为从 1 开始的代价，**不等价于保存搜狗真实词频**。
- 输出采用 Win32 `CREATE_NEW`，任何已存在目标均拒绝覆盖，输入文件不变；路径禁止设备名、流及父目录重解析点。另存前请选一个尚不存在的新文件名。

## 安全与限制

备份、安装与恢复由 GUI 明确确认；预览不需要管理员。完整备份采用 manifest v2 / FSD2，保存 Owner、Group、DACL、审计 SACL、完整性 label 及保护/继承控制位；不把读取失败降级为缺失权限信息。安全属性或内核能力不受支持时会拒绝操作，具体边界见部署说明。

格式依据公开逆向资料及用户样本，不是微软/搜狗官方兼容保证。WBC3 索引决定同码候选次序，未知 2+4 字节及 flag 不映射为频率；不保留学习历史、配置或皮肤。输入上限 128 MiB，选中的 WBC3 64 MiB，100 万条，ZIP 总声明膨胀 512 MiB/4096 条目；不支持 ZIP64、分卷、加密、UTF-16BE、ANSI 或任意文本词库方言。lex 单条文本最多 32759 个 UTF-16 单元，同码候选最多 65535。

正常 CTest 只用合成样本。可选真实样本验证（只读、不入库）：

```powershell
$env:LEXHELPER_CWB_SAMPLE='D:\路径\自己的备份.CWB'
ctest --preset debug --output-on-failure
```

该可选用例核对本次获授权样本的 70,870 条及码长统计，并执行全量 lex 语义往返；其他 CWB 仍可由 GUI 导入，但这组特定统计断言不适用。测试临时制品仅位于 `D:\temp\aiRunner\opencode` 的唯一目录。
